# 후쿠오카 여행 플래너 · 앱 버전

> **직접 고치고 싶을 때는 [docs/수정가이드.md](docs/수정가이드.md) 를 보세요.**
> 원본은 `src/` 폴더에 있고, 고쳐서 저장하면 깃허브가 앱 파일(`index.html` · `sw.js`)을 자동으로 다시 만들어요.

휴대폰 홈 화면에 설치해서 쓰는 앱 버전이에요 (PWA).
아이폰과 안드로이드 모두에서 아이콘으로 실행되고, 전체 화면으로 열리고, 한 번 열어 두면 인터넷이 없어도 열려요.

> 이 폴더의 파일을 무료 웹사이트에 한 번 올려야 휴대폰에 설치할 수 있어요.
> 파일을 컴퓨터에서 바로 열면(더블클릭) 설치 기능이 동작하지 않아요.

## 1. 인터넷에 올리기 (GitHub Pages, 무료 · 처음 한 번만)

1. https://github.com 에 가입하고 로그인해요.
2. 오른쪽 위 **+** → **New repository** 를 눌러요.
   - Repository name: `fukuoka-planner`
   - **Public** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 을 눌러요.
4. 이 폴더 안의 파일과 폴더(`index.html`, `manifest.webmanifest`, `sw.js`, `icons`, `photos`)를 **전부** 끌어다 놓고 **Commit changes** 를 눌러요.
5. 저장소의 **Settings → Pages** 로 가서
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)** → **Save**
6. 1~2분 뒤 같은 화면 위쪽에 주소가 나와요.
   `https://내아이디.github.io/fukuoka-planner/`

다른 무료 호스팅(Netlify, Cloudflare Pages 등)에 이 폴더를 그대로 올려도 똑같이 돼요.

## 2. 휴대폰에 설치하기

**아이폰**
1. **Safari** 로 위 주소를 열어요.
2. 아래쪽 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**.
3. 홈 화면의 "후쿠오카" 아이콘으로 열면 돼요.

**안드로이드**
1. **Chrome** 으로 위 주소를 열어요.
2. 화면에 뜨는 **설치** 안내를 누르거나, 오른쪽 위 **⋮** → **앱 설치**(또는 **홈 화면에 추가**).

## 3. 계획 공유하기 (친구 · 내 다른 폰)

1. 홈 화면 아래쪽 **계획 공유하기** 를 눌러요. 계획이 여러 개면 보낼 계획을 골라요.
2. **링크 보내기**(또는 **링크 복사**)로 카톡에 보내요.
3. 받는 사람이 링크를 누르면 **받은 여행 계획** 화면이 뜨고, **내 플래너에 넣기** 를 누르면 끝이에요.

같은 계획을 다시 받으면 더 최근에 고친 쪽으로 맞춰지고, 따로 사본으로 넣을 수도 있어요.

**링크가 잘 안 열릴 때 (고급)**
아이폰은 홈 화면에 설치한 앱과 사파리가 저장 공간이 따로라서, 링크를 누르면 사파리 쪽에 들어갈 수 있어요.
그럴 땐 받은 화면의 **코드 복사** 를 누르고, 설치한 앱에서 **계획 공유하기 → 고급 → 가져오기** 에 붙여 넣으세요.
같은 곳에서 코드나 파일로 백업해 둘 수도 있어요.

## 4. 고치기 · 새 버전으로 바꾸기

`src/` 안의 파일을 깃허브에서 고쳐 저장하면, **Actions** 탭의 「앱 만들기」가 자동으로 앱 파일을 다시 만들어요 (1분쯤).
초록 체크가 뜨고 1~2분 뒤 휴대폰에서 앱을 완전히 껐다 켜면 새 버전이 나와요. 저장해 둔 계획은 그대로 남아요.
`index.html` · `sw.js` · `manifest.webmanifest` 는 자동으로 만들어지는 파일이라 직접 고치지 마세요.

# 후쿠오카 플래너 수정 가이드

AI 없이 직접 고칠 때 보는 문서예요. 대부분은 **깃허브 웹사이트에서 파일을 열고 → 연필(✏️)로 고치고 → 저장**하면 끝나요.
컴퓨터에 아무것도 설치하지 않아도 돼요.

---

## 1. 한눈에 보기

```
planner/
├── src/            ← 원본. 고치는 건 전부 여기서 해요
│   ├── data.js       장소·동네·지하철역·요금·숙소 동네 (가장 자주 고치는 파일)
│   ├── spot_info.js  장소 정보 시트의 긴 설명·팁 (한국어·일본어)
│   ├── ja.json       일본어 사전 (화면 글자 한국어 → 일본어)
│   ├── home.js       홈 화면, 상단 사진, 동네 사진, 여행 일본어 문장, 계획 공유
│   ├── ui.js         새 여행 만들기, 일정 화면, 지도·교통비 탭, 공통 부품
│   ├── stays.js      숙소 날짜별로 정하기
│   ├── alt.js        웨이팅 길 때 근처 다른 식당
│   ├── guide.js      길안내 탭, 일본어로 보여주기(택시 카드)
│   ├── maps.js       지도 그리기
│   ├── engine.js     일정 짜기 계산 (규칙을 바꿀 때만)
│   ├── drag.js       일정 카드 끌어서 순서 바꾸기
│   ├── nav.js        안드로이드 뒤로가기
│   ├── i18n.js       일본어 화면 바꾸기 장치
│   └── style.css     색·글꼴·모양
├── photos/         ← 상단 사진(hero-…), 동네 사진(area-…)
├── icons/          ← 앱 아이콘
├── tools/          ← 앱 만드는 스크립트 (build.py), 점검 (check.js)
├── docs/           ← 이 문서
├── index.html  ┐
├── sw.js       ├─ 자동으로 만들어지는 결과물. ⚠️ 직접 고치지 마세요 (다음 저장 때 덮어써져요)
└── manifest.webmanifest ┘
```

**고치는 흐름**

1. 깃허브 저장소에서 `src/` 안의 파일을 열어요.
2. 오른쪽 위 연필(✏️ Edit this file)을 눌러 고쳐요.
3. **Commit changes...** → 다시 **Commit changes** 를 눌러 저장해요.
4. 저장소 위쪽 **Actions** 탭에 「앱 만들기」가 돌아가요 (노란 점 → 1분쯤 뒤 초록 체크 ✅).
5. 초록 체크가 뜨고 1~2분 뒤, 휴대폰에서 앱을 완전히 껐다 켜면 바뀌어 있어요.

**빨간 X ❌ 가 뜨면** 「앱 만들기」를 눌러서 빨간 단계를 펼쳐 보세요. `[만들기 실패]` 나 `[점검 실패]` 다음에
**어느 파일 몇째 줄이 왜 문제인지** 한국어로 나와요. 그 줄을 고쳐서 다시 저장하면 돼요.
실패한 동안에도 앱은 마지막으로 성공한 상태 그대로라서 망가지지 않아요.

**처음 한 번만 확인:** 「앱 만들기」가 `Permission denied` · `403` 같은 권한 오류로 실패하면,
저장소 **Settings → Actions → General → Workflow permissions** 에서 **Read and write permissions** 를 고르고 **Save** 한 뒤,
**Actions → 앱 만들기 → Run workflow** 를 눌러 다시 돌려 주세요.

> 글자를 찾을 때: 저장소에서 키보드 `t` 를 누르면 파일 찾기, 파일을 연 상태에서 `Ctrl+F`(맥은 `⌘+F`)로 글자 찾기가 돼요.

## 2. 자주 하는 수정

### 2-1. 맛집·명소 추가하기 — `src/data.js`

`const SPOTS = [` 아래에 장소가 동네별로 모여 있어요. 같은 동네의 비슷한 곳 덩어리 `{ ... },` 를 **통째로 복사해서 바로 아래에 붙여 넣고** 값만 바꿔요.

```js
  {
    id: 'ichiran_tenjin',      // 영어 소문자, 다른 곳과 겹치지 않게
    a: 'tenjin',               // 동네: hakata nakasu tenjin ohori momochi bayside dazaifu itoshima noko uminaka yanagawa yufuin beppu mojiko
    n: '이치란 텐진니시도리점', // 한국어 이름
    j: '一蘭 天神西通り店',      // 일본어 이름 (택시 카드·구글 지도 검색용)
    lat: 33.5905,              // 위도 ┐ 구글 지도에서 가게 자리를 길게 누르면
    lng: 130.3976,             // 경도 ┘ 맨 위에 「33.5905, 130.3976」 처럼 나와요
    c: 'food',                 // sight 명소 · food 맛집 · cafe 카페 · shop 쇼핑 · nature 자연·공원 · onsen 온천
    s: 40,                     // 머무는 시간(분)
    p: 3,                      // 우선순위 1~5 (높을수록 일정에 먼저 들어가요)
    meal: true,                // 식사 장소면 넣기 (점심·저녁 칸에 들어가요)
    d: '칸막이 자리에서 먹는 돈코츠 라멘.' // 일정 카드의 한 줄 설명
  },
```

필요할 때만 넣는 값 (없으면 빼도 돼요):

| 값 | 뜻 | 예 |
|---|---|---|
| `to: '15:00'` | 닫는 시간 (이후엔 일정에 안 넣어요) | 점심만 하는 우동집 |
| `from: '18:00'` | 여는 시간 | 포장마차 |
| `cl: [3]` | 쉬는 요일 (0=일 1=월 2=화 3=수 4=목 5=금 6=토) | 수요일 휴무 |
| `pd: true` | 저녁 식사로 추천 | 모츠나베 |
| `b: 'n'` | 추천 시간대 `'m'` 아침 · `'e'` 해 질 녘 · `'n'` 밤 | 야경 명소 |
| `se: [3, 4]` | 시즌인 달 (그 밖의 달엔 경고) | 벚꽃 명소 |

⚠️ 쉼표 주의: 덩어리 끝 `},` 의 쉼표, 각 줄 끝 쉼표를 빼먹으면 `[만들기 실패] … 문법 오류` 가 나요. 마지막 줄(`d: …`)에는 쉼표가 없어도 돼요.

**긴 설명·팁을 붙이려면** `src/spot_info.js` 에 같은 `id` 로 넣어요 (없어도 앱은 잘 돌아가요).

```js
  ichiran_tenjin: {
    pr: 2,                       // 가격대 1 ¥ · 2 ¥¥ · 3 ¥¥¥   (명소는 fee: 'free' 무료 · 'paid' 유료 · 'part' 일부 유료)
    ko: '한국어 긴 설명',
    ja: '日本語の説明',
    tk: '한국어 팁 (줄이 길면 「줄」이라는 말을 넣으면 대체 식당 목록에 「여기도 줄 서는 곳」이 떠요)',
    tj: '日本語のヒント'
  },
```

### 2-2. 장소 정보 고치기 · 빼기 — `src/data.js`

- **문 닫는 시간이 바뀜** → 그 장소 덩어리의 `to: '15:00'` 를 고쳐요.
- **휴무일** → `cl: [1]` 처럼 넣거나 고쳐요.
- **머무는 시간** → `s:` 숫자(분).
- **폐업** → 그 장소 덩어리 `{ ... },` 를 통째로 지우고, `src/spot_info.js` 에서 같은 id 덩어리도 지워요.
  (이미 만들어 둔 계획에 그 장소가 있으면, 그 계획에서는 그 칸만 사라져요)

### 2-3. 화면 글자 바꾸기

1. 바꾸고 싶은 문장을 `src/` 에서 찾아요 (`Ctrl+F`).
2. 문장이 **`L('한국어', '日本語')`** 안에 있으면 → 두 개를 같이 고치면 끝.
3. 그냥 한국어로만 적혀 있으면 → 한국어를 고친 뒤, **`src/ja.json` 에서 원래 한국어 문장을 찾아** 왼쪽(한국어)도 똑같이 고치고 오른쪽 일본어도 고쳐요.
   (안 고치면 일본어 화면에서만 그 문장이 한국어로 나와요. 앱이 고장 나지는 않아요)

### 2-4. 일본어 번역 고치기 · 추가 — `src/ja.json`

한 줄이 `"한국어": "日本語",` 예요. 한국어 쪽은 화면 글자와 **글자 하나 다르지 않게** 같아야 해요.

문장 안에 바뀌는 부분은 이렇게 적혀 있어요:

| 기호 | 뜻 | 예 |
|---|---|---|
| `{@}` | 장소·역 이름 | `"{@}까지 걷기": "{@}まで歩く"` |
| `{#}` | 숫자 | `"약 {#}분": "約{#}分"` |
| `{J}` | 이미 일본어인 부분 | `"{J} 방면": "{J}方面"` |

일본어 쪽 기호 개수가 한국어 쪽보다 많으면 `[만들기 실패]` 가 나요. 마지막 줄에는 쉼표가 없어야 해요.

### 2-5. 여행 일본어 문장 추가 — `src/home.js`

`const PHRASES = [` 아래에 `['한국어 뜻', '日本語', '읽는 법'],` 한 줄씩 넣으면 「여행 일본어」 목록에 나와요.

```js
  ['물 주세요', 'お水ください', '오미즈 쿠다사이'],
```

### 2-6. 사진 바꾸기 · 추가 — `photos/` + `src/home.js`

- **같은 이름으로 바꾸기**(가장 쉬움): `photos/` 폴더에서 **Add file → Upload files** 로 같은 파일 이름(예: `area-hakata.jpg`)을 올리면 덮어써져요.
  동네 사진은 가로 800 × 세로 480, 상단 사진은 가로 1080 정도면 충분해요 (용량 300KB 이하 추천).
- **상단 사진 추가**: `photos/` 에 `hero-day-6.jpg` 처럼 올린 뒤, `src/home.js` 의 `const HERO_PHOTOS` 에서 `day:`(낮) 또는 `night:`(밤) 목록에 덩어리를 하나 더 넣어요.

```js
    {
      f: 'hero-day-6.jpg',            // photos/ 안의 파일 이름
      by: '찍은 사람',                 // 사진 아래 출처 표시
      u: 'Unsplash사진주소끝부분',       // unsplash.com/photos/ 뒤의 글자 (출처 링크용)
      alt: ['한국어 사진 설명', '日本語の説明']
    },
```

- 동네 사진 출처는 `src/home.js` 의 `const AREA_PHOTOS` 에서 `동네id: ['찍은 사람', 'Unsplash 주소 끝부분'],` 를 고쳐요.
- 코드에 적은 사진이 `photos/` 에 없으면 `[만들기 실패] … 없는 사진` 으로 알려 줘요.

### 2-7. 요금 · 환율 — `src/data.js` 의 `const FARE`

각 줄 옆에 뜻이 적혀 있어요. 예: 택시 기본요금 `taxiBase: 600`, 지하철 1일권 `subwayCap: 640`,
원화 환산 기본값 `krwPer100: 837` (100엔 = 837원), 환율 기준일 `krwDate`.

### 2-8. 숙소 동네 추가 — `src/data.js`

세 군데에 같은 이름(예: `akasaka`)으로 넣어요.

1. `PLACES` 의 `hotel: {` 안: `akasaka: { j: '赤坂周辺', n: '숙소 (아카사카 주변)', lat: 33.5895, lng: 130.3912, z: 'city' },`
2. `const HOTEL_LABEL` 안: `akasaka: '아카사카',`
3. `const HOTEL_STATION` 안 (그 자리에 지하철역이 있으면): `akasaka: 'akasaka',`

(역 근처 숙소는 동네를 추가하지 않아도 앱의 「다른 역 근처」에서 모든 지하철역을 고를 수 있어요)

### 2-9. 색 바꾸기 — `src/style.css`

맨 위 `:root {` 안의 `--이름: #색;` 이 앱 전체 색이에요.
`--pri` 주 색(빨간 버튼), `--ink` 글자색, `--bg` 바탕색. 다크 모드 색은 그 아래 `@media (prefers-color-scheme: dark)` 안에 있어요.

## 3. 코드가 움직이는 방식 (조금 더 깊이)

- **합치는 순서**: `tools/build.py` 맨 위 `JS_FILES` 순서대로 한 파일로 합쳐서 `index.html` 을 만들어요. 위쪽 파일에서 만든 것을 아래쪽 파일이 써요.
- **상태 `S`** (`ui.js`): 지금 화면(`S.view`: home·dates·areas·plan), 열린 시트(`S.sheet`), 계획(`S.plan`) 등이 들어 있어요.
- **동작 `A`** (`ui.js` 와 각 파일의 `Object.assign(A, {...})`): 버튼에 `data-act="이름"` 을 달면 누를 때 `A.이름()` 이 실행돼요.
- **화면 그리기 `render()`**: `S` 를 바꾼 뒤 `render()` 를 부르면 화면 전체를 다시 그려요.
- **시트(아래에서 올라오는 창)**: `SHEETS.이름 = 그리는함수` 로 등록하고, `S.sheet = { type: '이름' }; render();` 로 열어요.
- **계획 저장**: 이 휴대폰 안(localStorage)에만 저장돼요. 계획 모양은 `engine.js` 의 `createPlan` 을 보면 돼요.
- **일본어 모드**: 새 코드는 `L('한국어', '日本語')`, 예전 코드는 `ja.json` 사전으로 바꿔요. 장소 이름·역 이름은 `data.js` 의 `j` 값으로 자동으로 바뀌어요.

## 4. 내 컴퓨터에서 미리 확인하기 (선택)

파이썬과 노드가 있으면:

```
node tools/check.js            # 일정 계산 점검
python3 tools/build.py --out 미리보기   # 미리보기 폴더에 앱 만들기
```

`미리보기/index.html` 을 크롬으로 열면 볼 수 있어요 (설치·오프라인 기능은 깃허브 주소에서만 돼요).
